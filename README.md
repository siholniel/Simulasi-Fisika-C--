# Simulasi Fisika 3D dengan C++ dan Raylib

Dua proyek visualisasi fisika sederhana.

## Isi

- `atom3d/` : awan probabilitas orbital hidrogen (bilangan kuantum n, l, m)
- `gravity3d/` : lengkungan ruang-waktu lubang hitam dengan partikel mengorbit

## Cara build (Windows, VS Code)

1. Pasang Git, MSYS2 (GCC + CMake), dan ekstensi CMake Tools di VS Code.
2. Buka salah satu folder proyek lewat File > Open Folder.
3. CMake: Configure, lalu CMake: Build, lalu CMake: Run Without Debugging.

Raylib diunduh otomatis oleh CMake.
